Core Features

Every feature designed with accessibility at its core

👁️

Real-Time Object Detection

YOLOv8-powered vision model detects obstacles, vehicles, pedestrians and more. Fused with ultrasonic + ToF sensor data from the ESP32 smart cane for sub-100ms alerts.

  • YOLOv8
  • OpenCV
  • Sensor Fusion
  • ESP32
🆘

Emergency SOS

One-tap or cane-button SOS instantly notifies emergency contacts with GPS location via SMS and email.

  • GPS
  • SMS/Email
  • Geolocator
🧭

Voice Navigation

Fully spoken turn-by-turn directions. All UI actions are announced via TTS, and voice commands are accepted.

  • Flutter TTS
  • Speech-to-Text
  • Maps API
📡

Smart Cane (BLE)

Paired over Bluetooth LE, the ESP32 cane streams ultrasonic, ToF, accelerometer, and gyroscope readings at 10 Hz with vibration haptic feedback.

  • BLE
  • Ultrasonic
  • ToF Sensor
  • IMU
🎙️

Scene Description

On demand, the AI narrates the full visual scene — objects, their directions and distances — as a natural language sentence.

  • AI Vision
  • NLG
  • TTS
🔐

Secure Auth

JWT-based access + refresh token flow. SQLite database (upgradable to PostgreSQL). All API routes are authenticated.

  • JWT
  • FastAPI
  • SQLAlchemy

Flutter Mobile App Setup

Step-by-step
1
Install Flutter SDK

Download the Flutter SDK for Windows from the official site

flutter.dev/get-started ↗
2
Extract & add to PATH

Extract to C:\flutter then add C:\flutter\bin to your system PATH

[Environment]::SetEnvironmentVariable("Path", $env:Path + ";C:\flutter\bin", "User")
3
Verify installation
flutter doctor

Fix any issues reported by flutter doctor (Android Studio, Chrome, etc.)

4
Run the mobile app
cd echo-assist-ai-phase1\echo-assist-ai\mobile
flutter pub get
flutter run -d chrome
